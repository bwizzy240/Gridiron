Model combines current-season form with a previous-season baseline pulled toward league average, using point differential, record, and home/away splits. Spread and total estimates use a normal-distribution points projection built from each team's scoring rates, blended with previous-season data the same way. Kalshi's live market price is shown for comparison and can auto-fill the odds fields, but never changes the model's own numbers. Not a guarantee, and it doesn't see injuries or coaching matchups yet. Data comes from ESPN's public but unofficial API and Kalshi's public market data, either of which could change without notice. Use it as one input, not the whole decision.
